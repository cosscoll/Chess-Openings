# Ouvertures d'échecs en 3D

Application interactive présentant les grandes ouvertures d'échecs en 3D avec Three.js, entièrement responsive.

## Structure du projet

- `index.html` : Page principale HTML.
- `style.css` : Feuille de styles CSS.
- `js/`
  - `openings.js` : Base de données des ouvertures et des coups.
  - `engine.js` : Moteur 3D Three.js pour l'échiquier et les pièces.
  - `main.js` : Logique de l'interface, navigation et animations (modules ES).

## Publication sur GitHub et GitHub Pages

1. Créez un nouveau dépôt sur GitHub.
2. Poussez l'ensemble de ces fichiers à la racine du dépôt.
3. Activez **GitHub Pages** dans les paramètres du dépôt (source : `main` branch, `/ (root)`).
4. Votre site est en ligne !
